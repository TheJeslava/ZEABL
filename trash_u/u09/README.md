# u09 XLRS-lite Concise-Stage2 Ablation

u09 is the model-bbox route variant of v0-9. For questions containing a
numeric reference bounding box, its stage1 prompt still includes the mapped
question coordinates, but crop selection uses the bbox generated by stage1.
The u09-specific stage2 prompt is the concise global-plus-crop prompt:

- the first image is the downsampled global view and the last image is the
  high-resolution crop;
- both images remain in the user turn and the concise middle instruction is
  used;
- the crop is derived from `model_bbox_raw`, not directly from the question
  bbox.

The prompt text, global-then-crop image order, global question coordinates,
model, processor, image resizing, generation settings, seed, attention,
The no-reference path uses the common global-plus-crop stage2 prompt and the
stage1-generated bbox.

The 150-sample experiment selects 50 evenly distributed rows from each numeric
reference-bbox category, using the same positions as the earlier v0-5 sample:

```text
Object properties/Object motion state   50 / 60
Object properties/Object color          50 / 800
Object properties/Object classification 50 / 800
```

Run it with:

```bash
./run_scripts/run_reference_50x3.sh
```

The authoritative output prefix is
`results/zoomearth-xlrs-reference-model-bbox-150`.
